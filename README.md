## 🛠️ AutoCAD Workflow

### Layer Structure
| Layer | Colour | Line Type | Purpose |
|-------|--------|-----------|---------|
| PLOT_BOUNDARY | Cyan | DASHED2 | Outer plot boundary |
| BUILDING_WALLS | White | Continuous | External & internal walls |
| ROOF | Yellow | Continuous | Roof outline & ridge |
| DIMENSIONS | Green | Continuous | All dimension lines |
| HATCHING | Grey | Continuous | Material hatches |
| ANNOTATIONS | Red | Continuous | Text labels & leaders |
| SECTION_CUT | Magenta | CENTER2 | Section cut line A-A |
| LANDSCAPING | Green | Continuous | Trees, garden, driveway |
| TITLE_BLOCK | White | Continuous | Drawing title block |

### Key AutoCAD Commands Used
`RECTANG` `OFFSET` `LINE` `TRIM` `EXTEND` `ARC` `BHATCH` `CIRCLE`
`DIMLINEAR` `DIMALIGNED` `QLEADER` `PLINE` `DONUT` `UNITS` `LIMITS`
